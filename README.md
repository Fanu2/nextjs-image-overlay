# Next.js Image Overlay Demo

This project demonstrates a web version of the React Native `ImageOverlay` effect using React and Next.js.

## 🚀 Features
- Background image with overlay color
- Configurable title and description
- Clean and minimal code structure

## 📦 Install
```bash
npm install
```

## 🔧 Develop
```bash
npm run dev
```

## 🌍 Deploy to Vercel
1. Push this repo to GitHub.
2. Go to [vercel.com](https://vercel.com).
3. Import the repo and deploy.

Enjoy building!
